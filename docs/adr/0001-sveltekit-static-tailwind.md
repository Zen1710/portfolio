# SvelteKit statis dengan Tailwind CSS v4

v2 menggantikan portfolio v1 (Next.js, repo `Zen1710/Porto`) dengan konten dan tujuan yang sama, tapi stack-nya SvelteKit + Svelte 5 + Vite + Tailwind CSS v4, TypeScript, pnpm. Semua halaman di-prerender dengan `adapter-static`, lalu di-hydrate dan pindah halaman lewat client-side navigation (link di-preload saat hover), jadi rasanya seperti SPA tapi HTML-nya sudah jadi sejak build. Form kontak v1 (Server Action + Resend + rate limit) sengaja dihapus: kontak cukup lewat link email dan LinkedIn, supaya situs tidak butuh server, secret, atau rate limit sama sekali. Budget yang dicek sebelum deploy: JS awal di bawah 50 KB gzip dan Lighthouse mobile minimal 95 di semua kategori. Kalau suatu hari butuh endpoint (mis. form kontak lagi), tambahkan lewat kode Worker di hosting yang sama (lihat ADR 0002), bukan dengan pindah adapter seluruh situs.
