# Changelog dari GitHub saat build, di-rebuild harian

Changelog dibuat dari commit di repo situs ini dan repo setiap Project yang tampil, diambil lewat GitHub REST API saat build. Karena situs statis, commit di repo Project lain tidak memicu build, sehingga Changelog bisa basi. Solusinya, workflow GitHub Actions terjadwal (`.github/workflows/rebuild.yml`, setiap hari 06:00 WIB, bisa juga dijalankan manual) membangun situs dari `main` lalu menjalankan `wrangler deploy` sendiri, bukan memicu Workers Builds. Alasannya: build di Actions otomatis punya `GITHUB_TOKEN` milik workflow (read-only), jadi Changelog tidak kena rate limit GitHub API yang terjadi pada build Cloudflare tanpa token. Deploy dari Actions butuh secret repo `CLOUDFLARE_API_TOKEN` (template "Edit Cloudflare Workers") dan `CLOUDFLARE_ACCOUNT_ID`. Push ke `main` tetap dideploy oleh Workers Builds; kalau Changelog di situ juga mau terisi, tambahkan secret build `GITHUB_TOKEN` di Cloudflare. Repo yang tidak bisa dibaca (kosong, private, atau kena rate limit) dilewati, supaya build tidak pernah gagal gara-gara GitHub.
