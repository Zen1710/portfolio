# Hosting di Cloudflare Workers Static Assets

Situs di-host gratis di Cloudflare Workers Static Assets, bukan Cloudflare Pages. Untuk project baru, Cloudflare mengarahkan ke Workers, dan kalau nanti dibutuhkan endpoint, kode Worker bisa ditambah tanpa pindah layanan. Deploy berjalan otomatis lewat Workers Builds yang terhubung ke repo GitHub baru (`Porto` v1 di-archive tapi tetap public): push ke `main` berarti tayang, sementara branch lain mendapat preview URL. Situs awalnya tayang di `<worker>.<subdomain-akun>.workers.dev`, lalu nanti dipindah ke domain sendiri yang disambungkan ke Worker yang sama. Supaya perpindahan itu tidak menyentuh kode, base URL (untuk canonical, sitemap, dan Open Graph) disimpan di satu config. Security headers (CSP, `Referrer-Policy`, `frame-ancestors`) ditulis di file `_headers`. Cloudflare Web Analytics dipasang lewat snippet manual, karena auto-inject hanya bekerja di domain yang di-proxy Cloudflare. CSP-nya harus mengizinkan beacon itu dan script tema inline.
